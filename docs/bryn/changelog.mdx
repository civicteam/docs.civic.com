<Update label="September 03, 2026" description="v0.1.82">

**Features**
- You can now configure the JSON path a webhook uses to read the event type, fixing issues with misclassified events

**Improvements**
- HubSpot industry enrichment now matches at a more granular level, improving the accuracy of ICP fit scoring
- Scoring configuration now accepts negative per-signal weights, letting you suppress a signal's contribution to Intent scores
- The HubSpot connection form now shows which credential type and scopes are required, making setup easier

**Bug fixes**
- Fixed an error that rejected valid scoring configurations containing negative signal weights

</Update>

<Update label="September 01, 2026" description="v0.1.80">

**Features**
- The audit log and activity feed now use "Load more" pagination, replacing numbered page controls for faster browsing on large logs
- Pipedrive is now available as an ingest source with guided setup, account matching, and organization ID support
- Audit log and activity feed can now be filtered by date range using presets or a custom calendar picker, and your selection is saved in the URL for easy sharing
- The run detail page now links directly to the account that triggered the run, so you can navigate to account details in one click

**Improvements**
- Moved the filters panel trigger into the search row alongside the date filter for a cleaner layout

**Bug fixes**
- Fixed an issue where accounts with numeric record IDs (such as those from Pipedrive) were not being identified correctly

</Update>

<Update label="August 31, 2026" description="v0.1.79">

**Features**
- The audit log now includes an Account column, letting you see which account each event belongs to, filter by account name, and click through to account details
- Each webhook in the Integrations tab now has its own account-matching configuration, so you can set up identifier mapping per webhook instead of applying one setting to all webhooks

**Improvements**
- The PWA splash screen now uses a light background, matching the default light-mode theme on most devices

</Update>

<Update label="August 27, 2026" description="v0.1.78">

**Features**
- When connecting a connector that supports enrichment, Bryn now asks whether to enable enrichment during setup, with enrichment turned on by default
- You can now create, view, and manage named ingest webhooks directly from the Integrations screen
- Accounts and individuals can now be marked as ignored, hiding them from lists, stats, and automated processing while still keeping their data so the action is fully reversible

</Update>

<Update label="August 24, 2026" description="v0.1.77">

**Features**
- Events sent to named webhooks now automatically match to accounts and trigger signals, with no extra configuration needed.

**Improvements**
- Transactional emails (welcome, onboarding reminders, review digest, and more) have been refreshed with updated colors, spacing, typography, and button styling.

</Update>

<Update label="August 21, 2026" description="v0.1.74">

**Features**
- Audit log entries now show the account they concern, with a link to open that account directly from the expanded entry

**Improvements**
- Activity, Audit and Accounts now share the same filter controls, with keyboard navigation and a one-click reset to clear every filter at once

</Update>
