<Update label="October 07, 2026" description="v0.1.122">

**Features**
- Redesigned configuration screens with sidebar tabs, scoring weights as sliders with save and discard controls, and a drawer-based mapping editor
- Person and company field mappings are now available directly on source forms
- Billing page now automatically syncs your subscription state so it always reflects your current plan
- Slack link previews now offer a three-option selector in connector settings
- Onboarding now auto-collapses completed steps and focuses the next action
- Signal-mapping rules now support flexible path expressions and boolean matching
- Onboarding progress banner now appears on every screen, showing your remaining setup steps with the ability to skip optional ones
- New billing state clearly shows when a trial has not yet started after an incomplete checkout
- Clay enrichment integration added, with enriched data now preferred when viewing account and contact details
- Context panel now appears inline on the page for a cleaner layout

**Improvements**
- Pipeline view now uses a consistent 24-hour window with accurate event counts

**Bug fixes**
- Fixed an issue where editing a connector could overwrite its saved configuration

</Update>

<Update label="October 07, 2026" description="v0.1.121">

**Features**
- Connector details now open in a side panel next to the pipeline map, so you can inspect a connector without losing sight of the full map

**Bug fixes**
- Fixed an issue where Plays triggered by campaign signups could fail to fire under certain timing conditions
- Fixed duplicate billing records being created in some cases during account provisioning
- Paused Explore trials now resume automatically when you add a valid payment method

</Update>

<Update label="October 02, 2026" description="v0.1.116">

**Features**
- Campaign membership now appears as a durable attribute on each person, so Plays can use it as a condition. When a membership ends, it is automatically removed.
- Pixel origins can now be set to allowed, blocked, or undecided, giving you more control over which sources send data.
- Accounts can now be sorted by timing.
- Runs now use day-based navigation, matching the Audit log experience.
- Single-workspace members can connect to MCP with a simpler URL that does not require specifying a workspace.
- The pipeline map now collapses gracefully on smaller screens.

**Bug fixes**
- Fixed an issue where MCP first-connect setup could fail to validate the request or resolve the correct user profile.
- Fixed the missing Add button when adding a new origin on the Pixel screen.
- Fixed a display issue where the Pixel configuration view could expose a signing secret.
- Fixed row and page headers overflowing on narrow screens.
- LinkedIn icons now appear correctly on person profile links.
- Best-fit rows now correctly open their associated account.
- Removed a non-functional chip from the Accounts header.
- Fixed an issue where the page could scroll unexpectedly in certain views.

</Update>
