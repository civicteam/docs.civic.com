<Update label="September 19, 2026" description="v0.1.99">

**Features**
- Workspace invitations now have a dedicated accept page where invited users can preview and join a workspace with a single click
- New Members settings page lets you invite teammates by email, resend or revoke pending invitations, and remove members from your workspace
- Email subject lines in Play email outputs now support template variables, so you can personalise subjects per account just like the email body

**Improvements**
- Play-triggered emails sent through the platform credential are now delivered with updated branding and contextual links
- Toggling the Internal or Ignored filters on the audit log now hides all entries for those accounts, not just the summary row
- Company enrichment data now surfaces faster after an event is received

**Bug fixes**
- Invitation links can now only be accepted by the email address they were sent to, preventing forwarded or misdelivered links from granting access to the wrong person
- Users who join a workspace that is still being set up now see a clear status screen instead of a broken redirect

</Update>

<Update label="September 17, 2026" description="v0.1.98">

**Features**
- Map company fields such as name, website, industry, employee count, and more from any source's configuration panel
- During onboarding, the Plays step now shows where your starter Plays will deliver, such as a Slack channel or email
- Invite team members to your workspace with shareable invite links
- Invited team members now receive an invite email automatically
- ICP discovery now tells you when your website could not be reached, instead of showing a generic error
- HeyReach Plays now include campaign resume controls
- The weekly digest now shows tracked-account figures that match your dashboard

**Improvements**
- When you connect the same enrichment provider more than once, each connection is now refreshed independently

**Bug fixes**
- Fixed a blank screen that could appear briefly after signing in or during onboarding
- Fixed the onboarding Plays step to correctly follow the starter template setup
- Fixed invite emails so the footer link renders correctly

</Update>

<Update label="September 16, 2026" description="v0.1.97">

- During onboarding, you can now preview suggested starter Plays and toggle each one on or off before going live
- A new admin role is available between owner and operator, giving workspace configuration access without billing or member management permissions
- Account detail now shows score breakdowns for fit, intent, and timing, along with which Play each account matched
- When setting up a data import, Bryn now suggests the fields your vendor supports so you can map them faster

**Bug fixes**
- Fixed an issue where connecting Slack could attempt to list too many channels, causing slowdowns

</Update>

<Update label="September 10, 2026" description="v0.1.89">

**Features**
- HeyReach is now available as an output connector for all workspaces
- View the source event behind any audit log entry to see exactly what data came in and how it was mapped
- Map LinkedIn URL, seniority and functional area from ingest payloads onto individual records

**Improvements**
- Leads whose company URL contains a shortened link are no longer incorrectly matched to the link-shortener domain, preventing bad company associations
- Enrichment from HubSpot and Pipedrive now writes person-level fields such as job title, owner and lifecycle stage to the individual record rather than the account

</Update>

<Update label="September 10, 2026" description="v0.1.88">

**Features**
- HeyReach output connector -- connect an API key, pick a campaign, and add leads to LinkedIn sequences directly from any Play
- Filter internal and suppressed traffic on the Accounts list and Audit log
- Events with a company URL but no email address are now matched to existing accounts by domain, so LinkedIn-sourced leads reach the right account automatically
- Recognized website visitors are now automatically correlated to your PostHog person profiles, with a new toggle on pixel settings to opt out

**Improvements**
- Company names from enrichment are now ranked more accurately, preventing taglines from being used as the company name

**Bug fixes**
- Fixed an issue where enriched company names could display a tagline instead of the actual company name

</Update>

<Update label="September 09, 2026" description="v0.1.87">

**Features**
- You can now pick an Instantly campaign from a searchable dropdown when configuring an output play, instead of entering a campaign ID manually.

**Improvements**
- HubSpot setup instructions are now displayed as step-by-step lists instead of dense paragraphs, making them easier to follow.
- The test-output action now clearly distinguishes between connectors that send live data and those that only verify connectivity.

</Update>

<Update label="September 08, 2026" description="v0.1.86">

**Features**
- The pixel beacon now maps to the "site visited" signal instead of "identified account", better reflecting what a page-view event actually reports. Onboarding, starter plays, and signal vocabulary have been updated to match. Existing mappings are migrated automatically and intent scoring weights carry over, so no action is needed.

**Bug fixes**
- Fixed an issue where changing the entity kind on a mapping was silently dropped on save, causing the change to revert.
- Webhook credentials now display labels that match each auth mode and vendor setup dialog, making it easier to configure integrations correctly.

</Update>

<Update label="September 08, 2026" description="v0.1.85">

**Features**
- Anonymous website visitors who arrive through a paid campaign now show UTM attribution on the account page immediately, without waiting for the visitor to identify themselves
- UTM parameters are now preserved across page navigations, so campaign attribution is no longer lost after the landing page
- HeyReach is now available as a data source with guided setup in the integrations catalogue
- You can now trigger Plays based on whether an account matched a specific UTM campaign

**Improvements**
- Pipedrive enrichment now works for accounts that have an organization link but no email address, so webhook-created accounts enrich automatically

**Bug fixes**
- Fixed an issue where the MCP connector setup page displayed an incorrect server URL, which caused connection failures for some MCP clients

</Update>

<Update label="September 04, 2026" description="v0.1.83">

**Improvements**
- Named webhooks now store the original payload as sent, so event-type suggestions and evidence in the account-matching panel reflect exactly what was received
- Custom signals already saved on a signal mapping now appear in the picker for reuse

**Bug fixes**
- Fixed an issue where the ICP-match Play could fire for accounts identified without an actual website visit
- Fixed signal-mapping picker so mapped events stay under their correct source heading instead of appearing in the wrong group
- Fixed a size limit that could cause large webhook payloads to be rejected during ingest

</Update>

<Update label="September 03, 2026" description="v0.1.82">

- The HubSpot connection form now shows which credential type and scopes are required, making setup easier

**Bug fixes**
- Fixed an error that rejected valid scoring configurations containing negative signal weights
